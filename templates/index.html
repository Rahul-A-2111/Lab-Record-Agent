IMPLEMENTATION OF BINARY SEARCH TREE

AIM:

To implement and test a Binary Search Tree (BST) in Java, supporting node insertion, search, and in-order, pre-order, and post-order depth-first traversals.

ALGORITHM:

  1. Start the execution.
  2. Define a Node class with integer data, left pointer, and right pointer.
  3. Read input values and recursively insert into the binary tree hierarchy preserving BST invariant.
  4. Perform in-order traversal (Left, Root, Right) to yield sorted numerical sequence.
  5. Stop execution.

PROGRAM:

public class BinarySearchTree {
  static class Node { int key; Node left, right; Node(int k){ key=k; } }
  Node root; void insert(int key) { root = insertRec(root, key); }
  Node insertRec(Node r, int k) {
    if(r==null) return new Node(k);
    if(k < r.key) r.left = insertRec(r.left, k);
    else if(k > r.key) r.right = insertRec(r.right, k);
    return r;
  }
}
